# 化验数据并入样品台账 · 使用说明

点一下按钮，把化验结果里还没进台账的行自动归档、追加进 `上库采矿厂2026-样品台账.xlsx`。

- 双击 `化验数据并入台账.exe` 就能用，不用装 Python
- 判不准归属的记录不会乱塞业务表，会单独进 `未知位置待定` 暂存表等你处理
- 每次写入前自动备份，写错了能退回去

---

## 一、怎么用

### 1. 打开程序

双击 `化验数据并入台账.exe`。

第一次打开时两个路径是空的（或指向训练材料），点「浏览…」选：

| 项 | 选什么 |
|---|---|
| 样品台账 | `上库采矿厂2026-样品台账.xlsx` |
| 化验结果 | 放 `2026xxxx上库采场Au.xls` 这些文件的目录 |

**选一次就够了**，程序会记住，下次打开自动带出。换了目录随时可以再改。

### 2. 点「更 新 数 据」

程序会：

1. 读一遍台账（约 10 秒，34,000 多条记录）
2. 扫一遍化验结果目录（80 个文件约 1 秒）
3. 算出哪些行还没进台账、各自该进哪张表
4. 在界面上列出来给你看

**这一步不写任何文件**，纯预演。

界面会显示类似：

```
待写入 169 条
  106 → 北部山头炮孔
   24 → 中铁十九局低品位堆场样
   24 → 剥离样
   15 → 未知位置待定（暂存）
```

### 3. 确认无误，点「确认写入台账」

会弹窗问一次，点「是」之后：

1. **先备份**（存到 `_out/backup/`，保留最近 10 份）
2. 写入台账
3. 自检：重新打开确认每张表行数确实增加了
4. 提示完成

### 4. 处理暂存表（如果有）

`未知位置待定` 是程序新建的第 29 张表，专门放"判不出该进哪张表"的记录。它有 6 列：

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| 分析编号 | 送样编号 | 基本分析金（g/T） | 取样位置 | 来源文件 | 建议目标表 |

**处理办法**：看 F 列的建议，把整行剪切到正确的表里，**再把暂存表里这一行删掉**。

删了也不会丢——台账判重是看编号的，行已经挪进业务表，下次运行不会重复写。

界面上会一直显示「暂存表待处理 N 条」，这个数只减不增才正常。攒到 200 条以上要留意，说明归档规则该补了。

### 5. 嫌两步麻烦：勾「一键直写」

勾上之后，「更新数据」= 扫描 + 归档 + 备份 + 直接写盘，不再停下来问。默认不勾。

## 二、它是怎么判断"该进哪张表"的

三层规则，先严后宽：

**第 1 层 · 经验投票（主力）**

从台账历史里反推「取样位置 → 哪张表」的出现频次。台账里 3,800 多种位置写法，只有 13 种会跨表，其余唯一对应。

- 位置只对应过 1 张表 → 直接用（现有数据里 148 条走这条）
- 位置跨 2 张表，但主频 ≥80% → 按主频走，日志标「多义」
- 否则往下走

**第 2 层 · 关键词规则**

位置写法没见过时，按 `config/rules.json` 里的关键词匹配：

```json
{"match": ["0.5-1.0g/t", "低品位堆场"], "sheet": "中铁十九局低品位堆场样"}
```

规则按顺序匹配，**先具体后通用**（`爆堆` 要排在 `剥离` 前面，否则爆堆样会被剥离样抢走）。

你可以自己加规则，改完存盘即可，不用动程序。

**第 3 层 · 兜底进暂存表**

两层都没判出来（或位置为空），不硬塞业务表，写进 `未知位置待定`，同时用送样编号前缀给个建议：

- `BS-` → 北部山头炮孔，`NS-` → 南部山头炮孔，`ZX-` → 中心矿段炮孔
- `LB-` → 路边矿，`EDC-` → 二堆场，`CRCC-` → 五道弯、十道弯运矿样
- `Y-YKDC-` / `B-YKDC-` → 原矿堆场山顶运矿样（这个前缀不唯一，只作建议）

---

## 三、判重规则

| 情况 | 处理 |
|---|---|
| 目标表里已经有这个分析编号 | 跳过 |
| 编号只在**别的表**里出现过 | **照写**，日志标「跨表存在」 |
| 判不出归属、但编号台账里已有 | 跳过（进暂存表就是重复垃圾） |
| 同一编号在多个文件里出现 | 取文件修改时间最新那份 |

## 四、命令行用法（可选）

```bash
# 预演（不写文件）
python cli.py

# 真写
python cli.py --apply

# 导出列标定（核对用）
python cli.py --profile

# 临时指定路径
python cli.py --ledger "D:\...\台账.xlsx" --lab "D:\...\化验结果"
```

预演会在 `_out/` 下留两份东西：

- `归档建议_MMDD-HHMM.csv` —— 每条记录判到哪张表、依据是什么
- `归档摘要_MMDD-HHMM.md` —— 按表汇总 + **按位置核对**（同一位置只判一次，核对这一节最省事）

## 七、几个要留意的点

**1. 台账别开着 Excel 的时候写**

程序会检测 `~$` 锁文件，开着会直接拦住提示你关掉。强行写会失败或写坏。

**2. 写完第一次打开 Excel 会重算一下**

openpyxl 保存会清掉公式的缓存值（台账里 `二堆场` I 列、`多元素分析实验` 的换算公式）。公式本身没丢，Excel 打开时自动重算，属正常。

**3. 写错了两步退回**

1. 关掉 Excel
2. 把 `_out\backup\` 里最近那份 `<原名>_并入<时间>.bak.xlsx` 复制回去，改回原名

**4. 化验室换了导出模板怎么办**

表头认列有两道保险：先按表头文字认，认不出按内容形态认。如果整个文件都认不出分析编号列，会跳过这个文件并记日志，不会写错数据。

**5. 台账里有 7 张表表头文字和实际列序不符**

`北部山头炮孔` A 列写着「样品编号」实际是分析编号；`排土场`/`低品位堆场样`/`爆堆样`/`路边矿`/`倒矿样` 写着「送样编号/分析编号」实际也是分析在前；而 `1-1剥离`、`前山Ⅱ号矿体-炮孔` 才是真的送样在前。

**程序不看表头，看内容形态**。`config\sheet_profile.json` 里能看到每张表的实测标定结果，想核对就打开它。
